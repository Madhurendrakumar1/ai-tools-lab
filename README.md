# AI Tools Lab

A beginner-friendly Python project containing sorting algorithms and utility functions. This project was created as a college practical assignment to practice Python programming, Git, and GitHub.

## Features

### Sorting Algorithm

- Bubble Sort

### Utility Functions

- `is_palindrome(s)` - checks whether a string is a palindrome.
- `count_words(text)` - counts the number of words in a text.
- `celsius_to_fahrenheit(c)` - converts Celsius to Fahrenheit.
